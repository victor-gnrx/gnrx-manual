# Introdução ao DDS

**Para que serve:** registrar os Diálogos Diários de Segurança: o tema, quem conduziu, quem esteve e as evidências.

{% hint style="info" %}
O DDS é um adicional. Ele aparece no seletor de módulos, em **Adicionais**, e funciona dentro dos módulos que a sua empresa contratou. O menu tem **Painel**, **DDS realizados**, **Agendas** e **Temas**.
{% endhint %}
