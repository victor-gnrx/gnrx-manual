# Integrações

**Para que serve:** ligar o GNRx a outros sistemas da empresa, por API e webhooks.

{% hint style="info" %}
**Quem pode fazer:** Gestor ou Administrador, com a permissão de ver as configurações da empresa.
{% endhint %}

## Antes de começar

* As integrações são da empresa. A tela é a mesma em todos os módulos.

## Passo a passo

{% stepper %}
{% step %}
### Abra as integrações

Clique em **Configurações › Integrações**.
{% endstep %}

{% step %}
### Consulte a documentação técnica

A API e os webhooks estão explicados no manual do módulo Gestão de EPIs, em **Integrações**.
{% endstep %}
{% endstepper %}

## Dúvidas comuns

<details>

<summary>Preciso configurar de novo na CIPA?</summary>

Não. A integração configurada vale para a empresa.

</details>

<details>

<summary>A tela é diferente da Gestão de EPIs?</summary>

Não. É a mesma tela de Integrações da Gestão de EPIs.

</details>
