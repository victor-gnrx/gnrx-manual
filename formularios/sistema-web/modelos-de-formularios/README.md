# Modelos de formulário

**Para que serve:** o modelo define os campos, as seções e as validações. Cada formulário é criado a partir de um modelo.

{% hint style="info" %}
Todas as roles veem os modelos. Criar, editar e inativar é do Gestor e do Administrador.
{% endhint %}
