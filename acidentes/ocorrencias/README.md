# Ocorrências

**Para que serve:** registrar tudo, do desvio ao acidente, e tratar cada ocorrência até o fim: triagem, investigação, CAT e plano de ação.

{% hint style="info" %}
Os quase-acidentes de hoje são os acidentes de amanhã. Registre também os desvios e os quase-acidentes.
{% endhint %}

{% hint style="warning" %}
**Dados de saúde:** CAT, CID, atestado e fotos de lesão do acidentado são dados sensíveis. Só Gestor e Administrador, com a permissão de ver dados de saúde do acidentado, veem essas informações.
{% endhint %}
