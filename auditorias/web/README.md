# Auditorias na web

**Para que serve:** montar os modelos de checklist, fazer as auditorias, tirar o relatório e tratar as não conformidades com planos de ação.

{% hint style="info" %}
No módulo Auditorias, o menu tem **Painel de Auditorias**, os modelos (**Modelos NRs**, **Modelos Customizados**, **Modelos Padrões** e **Categorias de Modelos**), **Estruturas** (**Usuários**, **Unidades** e **Setores**), **Configurações** (**Roles & Permissões** e **Integrações**) e as auditorias (**Auditorias**, **Planos de Ação** e **Agendamento de Auditorias**).
{% endhint %}
