# Modelos de auditoria

**Para que serve:** o modelo é o checklist que a auditoria segue. Toda auditoria nasce de um modelo.

| Tipo | Quando usar |
| --- | --- |
| **Modelos NRs** | Para auditar itens tirados da biblioteca de Normas Regulamentadoras. Veja [Criar um modelo NR](../modelo-nr.md). |
| **Modelos Customizados** | Para montar os seus próprios itens, de vários tipos (conformidade, foto, assinatura...). Veja [Criar um modelo customizado](../modelo-customizado.md). |
| **Modelos Padrões** | Para começar de um checklist pronto do GNRx. Ele vira um modelo customizado da empresa. Veja [Usar um modelo pronto](modelos-padroes.md). |

Para organizar muitos modelos, use as [categorias](categorias.md).
