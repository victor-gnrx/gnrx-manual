# Preencher uma auditoria

**Para que serve:** responder os itens da auditoria, registrar as evidências e finalizar.

{% hint style="info" %}
**Quem pode fazer:** todas as roles, com as permissões de editar e de finalizar auditorias.
{% endhint %}

## Antes de começar

* [Crie a auditoria](criar-auditoria.md).

## Passo a passo

{% stepper %}
{% step %}
### Inicie

Abra a auditoria e clique em **Iniciar**. Ela passa para **Em Andamento**.

<figure><img src="../.gitbook/assets/aud-preencher-01.png" alt="Auditoria aberta com o estado, o botão Iniciar e os itens da primeira seção"><figcaption><p>Auditoria aberta</p></figcaption></figure>
{% endstep %}

{% step %}
### Responda os itens

Em itens de conformidade, clique em **Conforme**, **Não conforme** ou **N/A**. Nos outros tipos, clique em **Editar**, preencha e clique em **Salvar**. Cada resposta é salva na hora.
{% endstep %}

{% step %}
### Registre as evidências

No item, use os ícones: chave para a ação corretiva (**Salvar Ação Corretiva**), câmera para fotos, folha para documentos e balão para observações (**Salvar**).

<figure><img src="../.gitbook/assets/aud-preencher-02.png" alt="Item não conforme com os ícones de ação corretiva, fotos, documentos e observações"><figcaption><p>Evidências do item</p></figcaption></figure>
{% endstep %}

{% step %}
### Marque o que já foi resolvido

Se a não conformidade foi corrigida na hora, clique em **Marcar resolvido**. Para mandar o item ao plano de ação, clique em **Requer ação**.
{% endstep %}

{% step %}
### Finalize

Clique em **Finalizar**. A auditoria fica **Finalizada** e bloqueada para edição.
{% endstep %}
{% endstepper %}

## Deu errado?

| Mensagem na tela | O que fazer |
| --- | --- |
| "Arquivo muito grande. Máximo: 10MB" | Envie uma foto menor. |
| "Formato não permitido." | Envie um arquivo num dos formatos aceitos. |
| "Digite um código válido." | Confira o código de barras digitado. |
| "Geolocalização não suportada pelo navegador." | Digite a latitude e a longitude, ou use o aplicativo. |

## Dúvidas comuns

<details>

<summary>Como reabro uma auditoria finalizada?</summary>

Clique em **Reabrir**. Ela volta para **Em Andamento**.

</details>

<details>

<summary>Como corrijo a unidade, o setor ou a data?</summary>

Na auditoria, clique em **Editar Auditoria**. Ajuste o nome, a descrição, a unidade, o setor ou a data e clique em **Salvar**.

</details>

<details>

<summary>Errei a resposta de conformidade?</summary>

Clique de novo na resposta marcada para limpar.

</details>

<details>

<summary>Pelo celular?</summary>

Também dá, até sem internet. Veja o [aplicativo](../aplicativo/preencher-auditoria.md).

</details>
