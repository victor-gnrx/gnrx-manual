# Tipos de produtos

**Para que serve:** organizar o que a empresa entrega: os tipos de EPI e os outros tipos de produto (máquinas, uniformes, equipamentos).

{% hint style="info" %}
No módulo Gestão de EPIs, clique em **Configurações › Tipos de Produtos**. A tela tem **Tipos de EPIs** (EPIs tradicionais do sistema) e **Outros Tipos de Produtos**.
