# Usuários e roles

**Para que serve:** controlar quem entra no GNRx e o que cada pessoa pode ver e fazer.

Três coisas definem o acesso de um usuário:

* **Role:** o que ele pode **fazer**.
* **Unidades:** de onde são os registros que ele **vê**.
* **Módulos:** quais módulos ele **usa**.
