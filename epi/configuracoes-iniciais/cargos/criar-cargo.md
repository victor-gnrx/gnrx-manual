# Criar um cargo

**Para que serve:** cadastrar uma nova função da empresa.

{% hint style="info" %}
**Quem pode fazer:** Administrador, com a permissão de criar cargos.
{% endhint %}

## Antes de começar

* Tenha o nome do cargo.

## Passo a passo

{% stepper %}
{% step %}
### Clique em Novo cargo

Clique em **Estruturas › Cargos** e depois em **Novo cargo**. Abre a janela **Criar cargo**.

<figure><img src="../../.gitbook/assets/cargos-criar-01.png" alt="Janela Criar cargo com o campo Nome e o botão Salvar"><figcaption><p>Janela Criar cargo</p></figcaption></figure>
{% endstep %}

{% step %}
### Preencha e salve

Digite o **Nome** (obrigatório, até 128 caracteres) e clique em **Salvar**. O cargo aparece na lista.
{% endstep %}
{% endstepper %}

## Deu errado?

| Mensagem na tela | O que fazer |
| --- | --- |
| "Nome é obrigatório" | Preencha o nome. |
| "Nome muito longo" | Use até 128 caracteres. |

## Dúvidas comuns

<details>

<summary>Como ligo o cargo a um colaborador?</summary>

No cadastro do colaborador, dentro do setor. Veja [Vincular setor e cargo a um colaborador](../colaboradores/vincular-setores.md).

</details>

<details>

<summary>Vale para todos os módulos?</summary>

Sim. O cargo é o mesmo em todos os módulos do GNRx.

</details>
