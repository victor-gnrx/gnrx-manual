# Empresas Terceiras

**Para que serve:** cadastrar quem presta serviço para a sua empresa, para controlar os colaboradores terceiros.

Há dois tipos:

* **Empresa (CNPJ):** pessoa jurídica, incluindo MEI.
* **Autônomo (CPF):** pessoa física sem CNPJ.

{% hint style="info" %}
Dentro do módulo, clique em **Estruturas › Terceiros**. Digite em **Pesquisar empresas...** para achar uma empresa e use o filtro de status para ver as ativas ou as inativas.
{% endhint %}
