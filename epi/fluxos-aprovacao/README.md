# Fluxos de aprovação

**Para que serve:** desenhar quem aprova cada solicitação (de itens, de compra, de transferência, análise de documento, liberação documental) e em qual ordem.

{% hint style="info" %}
No módulo Gestão de EPIs, clique em **Configurações › Fluxos de Aprovação**. **Minhas Aprovações** mostra o que espera a sua decisão e **Fluxos Travados**, o que parou sem aprovador.
{% endhint %}
