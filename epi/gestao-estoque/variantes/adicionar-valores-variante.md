# Adicionar valores a uma variante

**Para que serve:** acrescentar um valor novo numa variante que já existe (ex.: GG no Tamanho).

{% hint style="info" %}
**Quem pode fazer:** Gestor ou Administrador, com a permissão de editar itens de EPI.
{% endhint %}

## Antes de começar

* A variante precisa existir. Veja [Criar uma variante](configurar-tipos-variante.md).

## Passo a passo

{% stepper %}
{% step %}
### Abra a variante

No item, no cartão de variantes, abra a edição da variante.

<figure><img src="../../.gitbook/assets/inventario-variante-02.png" alt="Janela de edição da variante com os valores e o campo para adicionar"><figcaption><p>Editar variante</p></figcaption></figure>
{% endstep %}

{% step %}
### Adicione e salve

Digite os valores novos e salve. Aparece "Valores adicionados com sucesso!".
{% endstep %}
{% endstepper %}

## Deu errado?

| Mensagem na tela | O que fazer |
| --- | --- |
| "Valor é obrigatório" | Digite o valor. |
| "Existem valores duplicados" | Tire o repetido. |

## Dúvidas comuns

<details>

<summary>Posso apagar um valor usado?</summary>

Confira o estoque daquela combinação antes.

</details>

<details>

<summary>O valor novo aparece na entrada?</summary>

Sim, nas combinações da próxima entrada de estoque.

</details>
