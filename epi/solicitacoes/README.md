# Solicitações

**Para que serve:** pedir EPIs para um colaborador, aprovar, entregar (com assinatura) e registrar a devolução.

{% hint style="info" %}
No módulo Gestão de EPIs, o menu **Solicitações** tem **Nova Solicitação**, **Consultar Solicitações**, **Entrega Rápida**, **Entregar Produtos**, **Entregas — Assinaturas Pendentes** e **Devoluções — Retornos Pendentes**.
{% endhint %}
