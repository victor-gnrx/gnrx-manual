# Instrutores

**Para que serve:** cadastrar quem ministra os treinamentos. O instrutor pode ser **Interno (Colaborador)** ou **Externo**.

{% hint style="info" %}
No módulo Gestão de Treinamentos, clique em **Estruturas › Instrutores**. Use **Pesquisar instrutores...** e os filtros **Tipo** (Todos, Internos, Externos) e **Situação** (Ativos, Inativos).
{% endhint %}
