# Fazer um curso

**Para que serve:** assistir os módulos de um curso, na ordem.

{% hint style="info" %}
**Quem pode fazer:** o colaborador com acesso ao curso.
{% endhint %}

## Antes de começar

* [Entre no portal](entrar-no-portal.md).

## Passo a passo

{% stepper %}
{% step %}
### Abra o curso

No **Início**, toque no curso. Os que têm "Exigido para a sua função" são obrigatórios. Faça dentro do prazo.

<figure><img src="../.gitbook/assets/aluno-curso-01.png" alt="Página do curso no celular com o botão Começar e a lista de Módulos"><figcaption><p>Página do curso</p></figcaption></figure>
{% endstep %}

{% step %}
### Toque em Começar

Toque em **Começar**. O primeiro módulo libera.
{% endstep %}

{% step %}
### Assista o módulo

Assista o vídeo até o fim. A linha do tempo libera conforme você assiste. PDF e link contam quando você abre. Se pedir, tire a foto antes do módulo.

<figure><img src="../.gitbook/assets/aluno-curso-02.png" alt="Vídeo do módulo tocando no celular"><figcaption><p>Módulo em vídeo</p></figcaption></figure>
{% endstep %}

{% step %}
### Vá para o próximo

Aparece "Módulo concluído.". Toque em **Próximo módulo**. No fim, toque em **Fazer a prova**.
{% endstep %}
{% endstepper %}

## Deu errado?

| Mensagem na tela | O que fazer |
| --- | --- |
| "Este módulo libera quando você concluir o anterior." | Termine o módulo anterior. |
| "O vídeo parou de carregar. Volte aos módulos e abra de novo." | Toque em **Voltar aos módulos** e abra o módulo de novo. |
| "Este navegador não toca o vídeo..." | Abra o portal no Chrome ou no Safari. |
| "Este navegador não dá acesso à câmera. Abra o link no Chrome ou no Safari." | Abra o portal no Chrome ou no Safari. |
| "Não foi possível abrir a câmera. Permita o acesso à câmera nas configurações do navegador e tente de novo." | Permita a câmera nas configurações do navegador e tente de novo. |
| "Sem acesso a este curso" | Fale com o RH. |
| "A empresa exige reconhecimento facial: envie a foto." | Tire a foto para continuar. |
| "Cadastre o reconhecimento facial antes de continuar." | Peça ao RH ou ao SESMT para cadastrar o seu rosto. |
| "O rosto não corresponde ao colaborador." | Tire de novo, com boa luz, o rosto inteiro no quadro e sem boné nem óculos escuros. Pode tentar quantas vezes precisar. |
| "Falha na verificação facial" | Tente de novo daqui a pouco. |

## Dúvidas comuns

<details>

<summary>Posso parar e continuar depois?</summary>

Pode. Abra o curso de novo. A fileira "Continuar assistindo" ajuda a achar.

</details>

<details>

<summary>Por que pede foto?</summary>

Para confirmar que é você quem faz o curso. A foto é comparada com o cadastro do seu rosto. Ela só é pedida quando a empresa liga essa exigência.

</details>
