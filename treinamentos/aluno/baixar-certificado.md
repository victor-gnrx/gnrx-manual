# Baixar o certificado

**Para que serve:** ver os seus certificados e baixar o arquivo.

{% hint style="info" %}
**Quem pode fazer:** o colaborador, com os próprios certificados.
{% endhint %}

## Antes de começar

* [Entre no portal](entrar-no-portal.md).

## Passo a passo

{% stepper %}
{% step %}
### Abra Meus certificados

Toque no menu e em **Meus certificados**. Cada certificado mostra se está **Em dia**, **A vencer**, se **Vence hoje** ou se é **Sem validade**.

<figure><img src="../.gitbook/assets/aluno-certificados-01.png" alt="Tela Meus certificados no celular com a lista e o botão Baixar"><figcaption><p>Meus certificados</p></figcaption></figure>
{% endstep %}

{% step %}
### Baixe

Toque em **Baixar**.
{% endstep %}
{% endstepper %}

## Deu errado?

| Situação | O que fazer |
| --- | --- |
| "Sem arquivo" logo depois de concluir o curso | O PDF leva alguns segundos para ficar pronto (turma grande demora mais). Espere um pouco e abra de novo. |
| "Sem arquivo" num **Certificado externo** | Ele foi cadastrado sem anexo e não terá arquivo. Peça o arquivo ao RH ou ao SESMT. |
| "Sem arquivo" por muito tempo num certificado de turma ou do EAD | Peça ao RH ou ao SESMT para reemitir. |
| "Nenhum certificado ainda" | Ao concluir um curso, o certificado aparece aqui. |
| "Não foi possível baixar o certificado. Tente de novo." | Confira a internet e tente de novo. |

## Dúvidas comuns

<details>

<summary>O certificado está vencendo.</summary>

No curso, aparece **Fazer a reciclagem**. Toque para fazer de novo.

</details>

<details>

<summary>O que é "Certificado externo"?</summary>

É um certificado de outro lugar, que a empresa cadastrou para você.

</details>
