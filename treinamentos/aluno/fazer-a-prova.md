# Fazer a prova

**Para que serve:** responder a prova no fim do curso, para ser aprovado.

{% hint style="info" %}
**Quem pode fazer:** o colaborador que concluiu todos os módulos.
{% endhint %}

## Antes de começar

* [Conclua todos os módulos](fazer-um-curso.md). A prova libera depois deles.

## Passo a passo

{% stepper %}
{% step %}
### Abra a prova

No curso, toque em **Fazer a prova**. Se pedir, tire a foto antes da prova.
{% endstep %}

{% step %}
### Responda

Marque as respostas. Em algumas perguntas, marque todas as corretas.

<figure><img src="../.gitbook/assets/aluno-prova-01.png" alt="Pergunta da prova no celular com as opções para marcar"><figcaption><p>Prova</p></figcaption></figure>
{% endstep %}

{% step %}
### Envie

Toque em **Enviar respostas**. Aparece **Sua nota**: "Você passou na prova" ou "Não foi desta vez".

<figure><img src="../.gitbook/assets/aluno-prova-02.png" alt="Resultado da prova no celular com Sua nota"><figcaption><p>Resultado</p></figcaption></figure>
{% endstep %}
{% endstepper %}

## Deu errado?

| Mensagem na tela | O que fazer |
| --- | --- |
| "Marque uma opção." | Responda a pergunta antes de enviar. |
| "Não foi desta vez" + "Resta 1 tentativa." | Reveja os módulos e faça de novo. |
| "As tentativas acabaram. Fale com o responsável pelo treinamento." | Fale com o RH ou com o responsável. |
| "Falta concluir o restante do treinamento." | Você passou, mas falta outra parte, como a prática presencial. |
| "A empresa exige reconhecimento facial: envie a foto." | Tire a foto para continuar. |
| "Cadastre o reconhecimento facial antes de continuar." | Peça ao RH ou ao SESMT para cadastrar o seu rosto. |
| "O rosto não corresponde ao colaborador." | Tire de novo, com boa luz, o rosto inteiro no quadro e sem boné nem óculos escuros. Pode tentar quantas vezes precisar. |
| "Falha na verificação facial" | Tente de novo daqui a pouco. |

## Dúvidas comuns

<details>

<summary>Passei. E o certificado?</summary>

Aparece "Treinamento concluído. O certificado sai pela empresa.". Depois, veja em [Meus certificados](baixar-certificado.md).

</details>

<details>

<summary>Posso enviar sem responder tudo?</summary>

O sistema avisa. Se quiser, toque em **Enviar mesmo assim**.

</details>
