# Trocar o PIN

**Para que serve:** trocar o PIN de acesso e conferir para onde vão os avisos.

{% hint style="info" %}
**Quem pode fazer:** o próprio colaborador.
{% endhint %}

## Antes de começar

* Saiba o seu PIN atual.

## Passo a passo

{% stepper %}
{% step %}
### Abra Meu perfil

Toque no menu e em **Meu perfil**.

<figure><img src="../.gitbook/assets/aluno-perfil-01.png" alt="Tela Meu perfil no celular com os dados, os contatos e Trocar o PIN"><figcaption><p>Meu perfil</p></figcaption></figure>
{% endstep %}

{% step %}
### Troque o PIN

Em **Trocar o PIN**, digite o **PIN atual**, o **Novo PIN** e **Repita o novo PIN**. Toque em **Trocar o PIN**. Aparece "PIN trocado. Use o novo no portal e no app.".
{% endstep %}
{% endstepper %}

## Deu errado?

| Mensagem na tela | O que fazer |
| --- | --- |
| "O PIN atual não confere." | Digite o PIN atual de novo. |
| "Os dois PINs novos estão diferentes." | Digite o mesmo PIN novo nos dois campos. |
| "Evite números iguais." / "Evite sequências." / "Evite padrões repetidos." | Escolha outro PIN. Não use 111111, 123456, a data de nascimento nem o CPF. |

## Dúvidas comuns

<details>

<summary>O novo PIN vale no app também?</summary>

Vale. É o mesmo PIN para o portal e para o app GNRx Colaborador.

</details>

<details>

<summary>Como mudo o e-mail e o telefone dos avisos?</summary>

Em **Meu perfil**, ajuste o **E-mail** e os **Telefones** e toque em **Salvar contatos**. Aparece "Contatos salvos.".

</details>
